# 航途小岛 · Harbor & Home

[开始游玩](https://zhangle59151.github.io/rentgame/)

V2 小岛生活：全屏画布、可以拖动和双指缩放的群岛。建房会增加居民，扩建会解锁不同区域和对应的循环动画。

- 海风小居：修建、钓鱼、散步与读书。
- 日落咖啡湾：煮咖啡、闲聊与休息。
- 潮汐渔港：栈桥垂钓、搬运与鱼跃。
- 风铃花园：浇花、风车与蝴蝶。
- 星光海岸：弹琴、舞蹈与灯串。

## 操作

单指拖动，双指缩放；点居民打招呼。下方“建造”选房，再点空地。点击房屋升级。“新区域”解锁海湾。点 ◉ 隐藏界面进入观景。键盘方向键移动，+/- 缩放，Home 回到中心。

每 20 秒客船结算租金；房源超过客流时按入住率结算。离线收益最多 4 小时。进度保存在当前浏览器，兼容 V1 存档。设置里可以导出和导入存档。区域活动是视觉养成表现，收入仍来自出租屋。

## PWA 与开发

原生 HTML/CSS/JavaScript，Canvas 2D 原创图形，无外部依赖。运行 `python3 -m http.server 8080` 后访问 localhost:8080。GitHub Pages 使用 main / root。首次联网打开后缓存资源，可离线游玩。iPhone 在 Safari 分享菜单添加到主屏幕，Android 可从浏览器安装。网页本身已铺满视口；系统地址栏需要独立安装或浏览器全屏支持才能隐藏。

修改资源需递增 sw.js CACHE 版本和 index.html 资源版本。图形按设备像素比绘制（上限 2），正常约 30 FPS；系统减少动态效果或设置选项可降低动画。
